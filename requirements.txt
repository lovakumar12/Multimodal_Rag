# Multimodal RAG classroom project — all free, open-source, no API keys.
# Note: in the Colab notebook these are installed via a `!pip install` cell.
# This file is provided for reference / local (non-Colab) runs.

pymupdf          # PDF text + embedded image extraction (imported as `fitz`)
pdfplumber        # PDF table extraction
sentence-transformers   # local embedding model (all-MiniLM-L6-v2)
faiss-cpu         # local vector store / similarity search
pillow            # image handling
requests          # talk to the local Ollama server (http://localhost:11434)
matplotlib        # preview extracted images in the notebook

# Ollama itself is NOT a pip package — it's installed via:
#   curl -fsSL https://ollama.com/install.sh | sh
# and the model is pulled via:
#   ollama pull qwen2.5vl:3b
